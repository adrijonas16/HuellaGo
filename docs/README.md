# HuellaGo - Documento Base de Producto

## "Cada paseo deja huella."

Plataforma digital peruana para duenos de perros que centraliza servicios, eventos, rutas de paseo y comunidad pet friendly.

---

## Estructura de documentos

### 01-producto/
- **01-descripcion-producto.md** - Descripcion del producto, propuesta de valor, publico objetivo, funcionalidades principales (Mapa, Eventos, Rutas, Perfil de mascota, Comunidad, Marketplace).
- **02-arquitectura-modulos.md** - Arquitectura de modulos del sistema y permisos por rol de usuario.
- **03-flujos-usuario.md** - 8 flujos principales de navegacion detallados paso a paso.

### 02-diseno/
- **01-diseno-visual.md** - Paleta de colores, tipografias, estilos de componentes (botones, cards, mapas, badges, formularios, navegacion), estados de interfaz y microinteracciones.
- **02-pantallas-movil.md** - 25 pantallas moviles detalladas con objetivo, componentes, acciones, navegacion y textos.
- **03-pantallas-web.md** - 19 pantallas web detalladas con objetivo, componentes, acciones, navegacion y textos.
- **04-componentes-ui.md** - Sistema de componentes reutilizables: navegacion, cards, marcadores de mapa, filtros, formularios, estados.

### 03-estrategia/
- **01-mvp-roadmap.md** - MVP (funcionalidades, pantallas, validacion), Roadmap de 5 fases (24 meses), modelos de monetizacion, stack tecnologico recomendado.

### 04-branding/
- **01-branding-copys.md** - Personalidad de marca, slogans, textos para botones/tarjetas/estados, copys completos para landing page, recomendaciones UX.

### 05-prototipo/
- **01-prompt-mockups.md** - Guia para prototipo interactivo, flujos navegables, y prompt listo para copiar en Pencil/Claude Design/Figma.

## Resumen ejecutivo

| Aspecto | Detalle |
|---------|---------|
| Nombre | HuellaGo |
| Slogan | "Cada paseo deja huella" |
| Tipo | App movil + Web |
| Mercado | Peru (inicio: Arequipa) |
| Publico | Duenos de perros, negocios pet, organizadores de eventos |
| MVP | 10 pantallas movil + 4 paginas web |
| Stack | Flutter + Next.js + NestJS + PostgreSQL + Google Maps |
| Diferenciadores | Recrear ruta, Crear evento desde ruta, Huella del paseo, Perritos asistentes, Nivel de energia compatible |
| Monetizacion inicial | Planes para negocios (Gratis/Pro S/49/Premium S/99) |
| Meta MVP | 500 usuarios, 20 negocios, 5 eventos en Arequipa |
