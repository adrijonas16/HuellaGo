# HuellaGo - MVP, Roadmap y Monetizacion

## 14. Estructura del MVP

### Ciudad de lanzamiento: Arequipa
Arequipa es ideal para el MVP por:
- Tamano manejable (menos de 1M habitantes) para iterar rapido.
- Comunidad pet activa y creciente.
- Buena adopcion tecnologica.
- Costos operativos menores que Lima.
- Facilita validacion antes de escalar.

### Funcionalidades del MVP (v1.0)

**Incluido en MVP:**
1. Registro/login (email + Google)
2. Perfil de usuario basico
3. Perfil de mascota (1 perro minimo)
4. Mapa interactivo con servicios
5. Directorio basico (veterinarias, grooming, tiendas, hoteles)
6. Ficha de negocio (info, fotos, horarios, ubicacion, contacto)
7. Filtros basicos (categoria, distancia, abierto ahora)
8. Eventos basicos (crear, ver, inscribirse)
9. Rutas de paseo (ver, guardar)
10. Iniciar paseo con tracking basico
11. Fotos post-paseo (subir 3-5 fotos)
12. Resumen "Huella del paseo" (version basica)
13. Favoritos (guardar lugares y rutas)
14. Resenas y calificaciones (negocios y rutas)
15. Notificaciones basicas (eventos, recordatorios)
16. Landing page web
17. Formulario de registro de negocios (web)

**No incluido en MVP (espera a fases siguientes):**
- Comunidad / feed social
- Seguidores
- Recrear ruta
- Crear evento desde ruta
- Panel de negocio completo
- Dashboard de organizador
- Reservas online
- Pagos
- Panel administrativo completo (se usa uno basico interno)
- Recomendaciones personalizadas por IA
- Membresía premium
- Multi-mascota avanzado
- Chat entre usuarios
- Venta de entradas

### Pantallas esenciales del MVP

**Movil (10 pantallas):**
1. Splash + Onboarding
2. Registro / Login
3. Crear perfil de perro
4. Home
5. Mapa interactivo
6. Detalle de negocio/servicio
7. Lista de eventos
8. Detalle de evento + inscripcion
9. Iniciar/finalizar paseo + subir fotos + Huella del paseo
10. Perfil (usuario + perro + favoritos)

**Web (4 paginas):**
1. Landing page
2. Registro de negocio (formulario)
3. Directorio de servicios (pagina publica)
4. Pagina de eventos (pagina publica)

### Flujo completo que debe funcionar desde el dia 1

```
Registro > Crear perro > Ver mapa > Encontrar veterinaria > Ver ficha > Guardar favorito
Registro > Crear perro > Ver eventos > Inscribirse > Asistir > Subir fotos > Huella del paseo
Negocio > Registrar en web > Aparecer en mapa > Recibir contactos
```

### Validacion con usuarios reales
- **Pre-lanzamiento**: encuesta a duenos de perros en Arequipa (Instagram, grupos de WhatsApp, parques).
- **Beta cerrada**: 50-100 usuarios invitados + 10-15 negocios pet reales.
- **Metricas a validar**: registros, perros creados, uso del mapa, inscripciones a eventos, fotos subidas, retorno semanal.
- **Feedback**: formulario in-app, entrevistas 1-a-1 con usuarios beta.

### Atraer primeros negocios
- Visitar veterinarias y groomers en persona en Arequipa.
- Ofrecer registro gratuito y perfil completo gratis por 6 meses.
- Pre-cargar informacion basica de negocios pet conocidos (nombre, direccion, horario).
- Mostrar beneficio: "Apareces en el mapa cuando alguien busca veterinarias cerca".

### Atraer primeros eventos
- Alianza con 1-2 municipalidades de Arequipa para mascotatones.
- Crear 2-3 eventos propios de HuellaGo ("Primer paseo grupal HuellaGo").
- Invitar a grupos de rescate animal a publicar sus eventos.
- Contactar marcas de alimento para mascotas para co-crear eventos.

### Crear comunidad al inicio
- Incentivar subida de fotos post-paseo (gamificacion basica: "Tu primera Huella!").
- Destacar paseos y rutas en redes sociales de HuellaGo.
- Crear cuenta de Instagram/TikTok con contenido de perros de la comunidad.
- Sorteos mensuales: "Sube tu mejor Huella del paseo y gana [premio pet]".

## 15. Roadmap por Fases

### Fase 1: MVP (Mes 1-4)
- Registro y autenticacion
- Perfil de usuario y mascota
- Mapa interactivo con servicios
- Directorio de negocios (pre-cargado)
- Fichas de negocio con contacto
- Filtros basicos
- Eventos (crear, ver, inscribirse)
- Rutas (ver, guardar)
- Paseo con tracking basico
- Fotos post-paseo
- Huella del paseo (version basica)
- Favoritos
- Resenas y calificaciones
- Landing page web
- Formulario de registro de negocios
- **Meta**: 500 usuarios, 20 negocios, 5 eventos en Arequipa.

### Fase 2: Comunidad + Rutas avanzadas (Mes 5-8)
- Feed de comunidad (publicaciones con fotos)
- Dar huellita (like) y comentar
- Seguir usuarios y perros
- Crear rutas (trazar en mapa)
- Recrear ruta (repetir ruta anterior)
- Calificacion avanzada de rutas (seguridad, sombra, limpieza, trafico)
- Perfil de mascota enriquecido (amigos perrunos, historial)
- Notificaciones push mejoradas
- Multi-mascota (registrar varios perros)
- Mejoras de UX basadas en feedback de Fase 1
- **Meta**: 2,000 usuarios, 50 negocios, 15 eventos/mes.

### Fase 3: Negocios + Expansion (Mes 9-14)
- Dashboard de negocio completo
- Estadisticas para negocios (visitas, llamadas, resenas)
- Promociones para negocios
- Planes de negocio (Gratis / Pro / Premium)
- Verificacion de negocios (badge)
- Reservas online basicas
- Responder resenas
- Panel administrativo completo
- Expansion a Lima
- App web completa (no solo landing)
- **Meta**: 10,000 usuarios, 200 negocios, expansion a Lima.

### Fase 4: Eventos avanzados (Mes 15-18)
- Crear evento desde ruta
- Dashboard de organizador de eventos
- Perritos asistentes (ver que perros iran)
- Cupos avanzados con lista de espera
- Check-in en eventos (QR)
- Galeria post-evento
- Historial de eventos asistidos
- Venta de entradas (integracion Mercado Pago / Yape)
- Paquetes para organizadores
- **Meta**: 25,000 usuarios, eventos semanales en Arequipa y Lima.

### Fase 5: Inteligencia y escala (Mes 19-24)
- Recomendaciones personalizadas segun perfil del perro
- Eventos sugeridos por nivel de energia y tamano
- Rutas seguras recomendadas
- Alertas de salud y recordatorios de vacunas
- Nivel de energia compatible (match evento-perro)
- Tendencias por ciudad
- Expansion a Cusco, Trujillo, Chiclayo
- API para integraciones
- Membresía premium para usuarios (si hay demanda validada)
- **Meta**: 100,000 usuarios, presencia en 5+ ciudades.

## 16. Monetizacion

### Modelos de ingreso

#### Al inicio (Fase 1-2): Gratis para todos
- Prioridad: crecimiento de usuarios y negocios.
- Todo gratis: registro, mapa, eventos, rutas, fotos.
- Ingresos: ninguno directo. Se busca traccion y validacion.
- Financiamiento: capital propio, amigos/familia, o pre-seed.

#### Fase 3: Primeros ingresos
| Modelo | Descripcion | Precio estimado |
|--------|-------------|-----------------|
| Plan Pro para negocios | Estadisticas, promociones, badge verificado, prioridad en busqueda | S/ 49/mes |
| Plan Premium para negocios | Todo Pro + reservas, destacado, soporte prioritario, multi-sucursal | S/ 99/mes |
| Promociones destacadas | Negocio aparece primero en su categoria/zona | S/ 30/semana |

#### Fase 4: Ingresos diversificados
| Modelo | Descripcion | Precio estimado |
|--------|-------------|-----------------|
| Comision por reservas | % de cada reserva hecha a traves de la app | 5-10% del servicio |
| Venta de entradas a eventos | Comision por entrada vendida | 5-8% + fee fijo |
| Paquetes para organizadores | Herramientas avanzadas de gestion de eventos | S/ 29-99/evento |
| Publicidad segmentada | Marcas pet que quieren llegar a duenos de perros de una zona | CPM/CPC |

#### Fase 5: Escala
| Modelo | Descripcion | Precio estimado |
|--------|-------------|-----------------|
| Alianzas con marcas | Patrocinios de eventos, rutas patrocinadas, contenido de marca | Negociable |
| Membresía HuellaGo+ | Para usuarios: stats avanzados, huella premium, sin publicidad, badges exclusivos | S/ 9.90/mes |
| Marketplace de productos | Venta de productos pet con comision | 10-15% comision |
| Data insights (anonimizado) | Tendencias del mercado pet para marcas | B2B |

### Recomendacion de priorizacion
1. **Primero**: Planes para negocios (Pro/Premium) - ingreso recurrente y predecible.
2. **Segundo**: Comision por reservas - se activa solo cuando hay volumen.
3. **Tercero**: Eventos con entrada - comision natural.
4. **Cuarto**: Publicidad segmentada - cuando hay base de usuarios grande.
5. **Quinto**: Membresía usuario - solo si hay features que justifiquen el pago.

## 17. Sugerencia Tecnica - Stack Tecnologico

### Frontend Movil
- **Framework**: Flutter (Dart)
  - Razon: un solo codebase para iOS y Android, excelente rendimiento, gran ecosistema de packages para mapas y camara.
  - Alternativa: React Native con Expo.

### Frontend Web
- **Framework**: Next.js 14+ (React, TypeScript)
  - Razon: SSR para SEO (landing, directorio), App Router, excelente DX.
  - Styling: Tailwind CSS
  - Componentes: shadcn/ui como base, personalizados con el design system de HuellaGo.

### Backend
- **Framework**: NestJS (Node.js, TypeScript)
  - Razon: modular, escalable, excelente para APIs REST, buena integracion con PostgreSQL.
  - Alternativa: .NET 8 (si el equipo tiene experiencia).
- **API**: REST (MVP) con posibilidad de migrar a GraphQL en fases posteriores.
- **Autenticacion**: JWT + refresh tokens, OAuth2 (Google, Apple, Facebook).

### Base de Datos
- **Principal**: PostgreSQL 16+ con PostGIS (extension para datos geograficos/mapas).
- **Cache**: Redis (para sesiones, datos frecuentes del mapa).
- **ORM**: Prisma (NestJS) o TypeORM.

### Mapas
- **API**: Google Maps Platform
  - Maps SDK para Flutter (movil)
  - Maps JavaScript API (web)
  - Directions API (rutas)
  - Places API (busqueda de lugares)
  - Geocoding API
  - Alternativa: Mapbox (mas personalizable, potencialmente mas barato a escala).

### Almacenamiento de Imagenes
- **Servicio**: Cloudinary
  - Razon: optimizacion automatica, transformaciones, CDN, tier gratuito generoso.
  - Alternativa: AWS S3 + CloudFront, Firebase Storage.

### Notificaciones Push
- **Servicio**: Firebase Cloud Messaging (FCM)
  - Razon: gratis, soporta iOS y Android, integrado con Flutter.

### Infraestructura
- **Hosting backend**: Railway o Render (MVP), AWS/GCP (escala).
- **Hosting web**: Vercel (Next.js).
- **CI/CD**: GitHub Actions.
- **Monitoreo**: Sentry (errores), Mixpanel o Amplitude (analytics).

### Modulos Tecnicos
```
src/
  modules/
    auth/          - Registro, login, JWT, OAuth
    users/         - CRUD usuarios, perfiles
    pets/          - CRUD mascotas, galeria, salud
    businesses/    - CRUD negocios, servicios, horarios, verificacion
    events/        - CRUD eventos, inscripciones, asistentes
    routes/        - CRUD rutas, trazado, calificacion
    walks/         - Tracking paseos, "Huella del paseo"
    photos/        - Upload, galeria, optimizacion
    reviews/       - Calificaciones, comentarios, reportes
    favorites/     - Guardados por usuario
    community/     - Feed, publicaciones, likes, follows
    notifications/ - Push, in-app, recordatorios
    bookings/      - Reservas, confirmacion
    admin/         - Panel administrativo, moderacion
    search/        - Busqueda full-text, filtros, geo-queries
    analytics/     - Metricas, estadisticas, reportes
```
